# Technical Specifications

This directory contains technical specifications for openDesk Nix components.

## 📁 Structure

- **technical/** - Component specifications (SOGo, Dev-Agent, ZOT, etc.)
- **compliance/** - Compliance and security specifications
- **api/** - API specifications
- **architecture/** - Architecture decision records

## 📝 Specification Types

### Technical Specifications
- SOGo 5/6 container specifications
- Dev-Agent specifications
- ZOT Registry specifications

### OpenSpec Artifacts
See [openspec/](../openspec/) for:
- Change proposals
- Design documents
- Task breakdowns
- Delta specs
